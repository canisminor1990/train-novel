# 产品画像

平台：web

产品类型：本机小说训练控制台。Python 服务只监听 127.0.0.1:8765，页面由 `web/` 的 Vite 应用构建后交给这个服务。包管理是 pnpm。扫描器只读了仓库根，根上没有 `package.json`，所以它没报出 Vite 和 `@lobehub/ui`。

用户：这本书的作者本人，在自己的 Windows 和一张 RTX 4090 上操作。没有账号，也没有其他角色。训练一次会看很久，平时不是每天打开。

核心任务：

- 一次导入多本自己的小说（分不分章都行），切成「命题 → 一整章」样本，并反推命题
- 选 Qwen3.5-4B 或 9B，在试跑、标准、细读里选一个预设
- 开始或停止这一次 SFT
- 看清加载、训练、保存、合并、导出 GGUF、挂载 Ollama 进行到哪
- 挂载完成后，给 Ollama 里的项目模型一个命题和字数，写出一章

copy-profile: admin

人称用无主语。预设名保持「试跑 / 标准 / 细读」。模型名、LoRA、GGUF、Ollama 不翻译。

## 适用性

| 结论 | 内容 |
| --- | --- |
| 强调 | 训练进度是主屏：当前阶段、步数、loss。作者要决定等下去、停掉，还是等挂载完成后去续写 |
| 强调 | 配置只有三个预设。不把学习率、rank、序列长度铺成一张手调表 |
| 强调 | 停止训练要写明后果：停的是当前进程，已经保存的 LoRA 还在 |
| 不适用 | 多用户、审批队列、计费对账、把这个后台暴露到公网 |
| 不适用 | 在页面里再做一套和 Ollama 平行的对话产品 |
